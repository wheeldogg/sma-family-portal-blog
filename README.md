# SMA Family Portal Blog

## Open the project
```bash
cd ~/Documents/workspace/projects/sma-family-portal-blog
```

## Main report
```bash
congress-report-budapest-2026.md
```

## Images
```bash
assets/images/congress-budapest-2026/
```

## Preview locally
```bash
bundle install
bundle exec jekyll serve
```

Open:
`http://127.0.0.1:4000/sma-family-portal-blog/congress-report-budapest-2026/`

## If images are missing
- make sure you ran `bundle exec jekyll serve` from the repo root
- refresh the page after the site builds
- check the images exist in `assets/images/congress-budapest-2026/`
